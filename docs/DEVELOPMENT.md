# Development Guide

[中文](DEVELOPMENT.zh-CN.md)

## Setup

Install Node dependencies with `npm ci`. Create a Python virtual environment inside `pdfplumber-fastapi-service/` if you need PDF parsing, then install its requirements.

```bash
npm ci
python -m venv pdfplumber-fastapi-service/.venv
pdfplumber-fastapi-service/.venv/Scripts/python -m pip install -r pdfplumber-fastapi-service/requirements.txt
```

On macOS and Linux, use `.venv/bin/python` instead. Copy `.env.example` to `.env` and set development-only values. `config.js` is generated by `node inject_env.js`; it is intentionally ignored.

## Run and Test

```bash
npm start
npm test
```

The Node server serves the static application and invokes the PDF parser with `PYTHON_BIN`. Check `GET /healthz` after starting the service.

## Contribution Rules

- Keep credentials, generated files, dependencies, caches, and build artifacts out of Git.
- Update the corresponding `.zh-CN.md` file whenever an English reader-facing document changes.
- Add focused tests under `tests/` for changes to reusable parsing or time utilities.
