# Phase 3: Mobile UI Polish & Settings

## Goals
Refine the mobile application user interface to provide a complete user experience, including visual feedback for events on the calendar, detailed daily views, and global settings management.

## Tasks

### T7-1: Calendar Event Indicators
- **Objective**: Visualize events on the monthly calendar.
- **Action**:
  - Update `CalendarMonth.tsx` to filter and render event dots for each day.
  - Use different colors for morning/afternoon/evening classes.
  - Limit the number of dots to prevent overflow (e.g., max 4 dots).

### T7-2: Day Detail View
- **Objective**: Show detailed course information when a user taps a date.
- **Action**:
  - Implement a `DayScheduleModal` or Bottom Sheet in `CalendarScreen`.
  - Display a timeline or list of courses for the selected day.
  - Show time, course name, location, and teacher.

### T7-3: Settings & State Management
- **Objective**: Allow users to configure the semester context.
- **Action**:
  - Implement `SettingsScreen.tsx`.
  - Add "Semester Start Date" configuration (affects "Current Week" calculation).
  - Move "Clear All Data" from Import screen to Settings.
  - Display App Version and Core Version.

## Execution Order
1. **T7-1**: Visual feedback first.
2. **T7-2**: Interaction detail next.
3. **T7-3**: Configuration last.
